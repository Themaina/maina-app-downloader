# Marketplace listing copy (maina888)

**Name:** Smart App Downloader
**Tagline:** One link that sends every visitor to the right app download.
**Category:** Utilities / Marketing
**Price:** Free (MIT)
**Compatibility:** Botble CMS core 7.3.0+, PHP 8.2+, any theme

**Short description**
Share a single `/download` link. iPhone and iPad visitors go to the App Store, Android to Google Play (or Huawei AppGallery / Amazon Appstore), Windows and Mac to your installer, and everyone else gets a minimal chooser page in your theme.

**Highlights**
- Automatic device detection and redirect from one URL, 8 platforms
- Four page designs (Minimal, Hero, Split, Tiles) that adapt to your theme colours
- Upload installers (.apk, .exe, .dmg, Linux packages) straight from the admin
- Branding: app name, pitch, icon and "Open in app" deep link
- Daily visit counter per platform, with no personal data stored
- Built-in downloadable QR code
- English, Vietnamese, Spanish, French and Arabic
- CDN-safe headers, http(s)-only link validation, clean uninstall

**Cover image / screenshots to attach**
1. Cover: `/download` redirecting from phone / laptop to the stores
2. Admin settings page
3. Chooser page on desktop and on mobile
4. Visit stats and QR code
